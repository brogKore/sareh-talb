# صارح طالب - نسخة دفعة سياحة رياضية

مشروع React + Vite بسيط لنسخة مبسطة من "صراحة" موجهة لدفعة سياحة رياضية.

## مميزات
- رسائل مجهولة
- تسجيل دخول Google / Facebook (Firebase Auth)
- وضع داكن / فاتح
- فلترة وحذف من لوحة المشرف
- فلترة كلمات أساسية وبلاغات

## خطوات تشغيل محلي
1. ثبت Node.js v18+.
2. استخرج الملفات.
3. نفذ:
   npm install
   npm run dev
4. افتح المتصفح على العنوان الموجود في الطرفية.

## ربط Firebase
1. أنشئ مشروع في Firebase.
2. فعّل Authentication -> Google وFacebook.
3. أنشئ Firestore.
4. انسخ مفاتيح المشروع وضعها في ملف `.env` استنادا إلى `.env.example`.

## نشر على Vercel
1. سجل في vercel.com.
2. اربط المستودع أو اسحب المجلد محلياً.
3. ضع متغيرات البيئة في إعدادات المشروع على Vercel.
4. انشر.

## ملاحظات أمنية
